Función Cuadrática, Factorización y Parábolas

Antes de recitar fórmulas de memoria, vamos a construir las herramientas con las manos: verás por qué multiplicar dos paréntesis es partir un rectángulo en cuatro parcelas, cómo desarmar trinomios rebobinando ese mismo proceso y cómo leer el vértice, las raíces y el discriminante en las tres vestimentas de una misma parábola.

Capítulo 1 · Pizarrón 1 de 10

1. Del Rectángulo al Polinomio: Multiplicar Binomios sin Memorizar Flechitas

En el colegio suelen enseñar a multiplicar dos paréntesis como (x + 3) · (x + 2) dibujando un arcoíris de flechitas mecánicas («el primero con el primero, el primero con el segundo...»). El problema de las recetas sin dibujo es que en medio de un examen te olvidás de una flecha y perdés todo el ejercicio. Miremos qué pasa en el mundo físico: imaginá un terreno rectangular cuyo ancho mide x + 3 metros y cuyo alto mide x + 2 metros. Si trazás una línea vertical donde termina x y otra horizontal donde termina x, el terreno queda partido en cuatro parcelas a la vista: un cuadrado principal de área x2, dos franjas rectangulares de áreas 3x y 2x, y una esquina numérica de 3 · 2 = 6. Al sumar las cuatro parcelas y juntar las dos franjas del mismo tipo (3x + 2x = 5x), nace la forma polinómica x2 + 5x + 6.

¿Y qué pasa cuando en un paréntesis aparece una resta, como en (x − 4)(x + 7)? Aunque en una maderera nadie vende tablas de «−4 metros», el modelo de área funciona como una contabilidad exacta de superficies y descuentos: las parcelas con signo positivo suman área (x2 y +7x) y las parcelas que multiplican por −4 descuentan área (−4x y −28), dejando un saldo neto de x2 + 3x − 28.

Los dos Productos Notables vistos con los ojos

1. Cuadrado de un binomio (a + b)2 = a2 + 2ab + b2: Cuando el terreno es un cuadrado perfecto de lado x + 3 por x + 3, además del cuadrado x2 y la esquina 32 = 9, en las diagonales aparecen dos rectángulos gemelos de área 3x cada uno. Juntos suman el doble producto +6x. Por eso (x + 3)2 jamás es x2 + 9.

2. Diferencia de cuadrados (a + b)(a − b) = a2 − b2: Cuando multiplicás una suma por su resta conjugada, como (x + 3)(x − 3), una franja lateral suma +3x y la otra descuenta exactamente −3x. Los dos rectángulos cruzados son opuestos y se neutralizan sumando 0, dejando únicamente x2 − 9.

Llamamos función cuadrática a toda relación que, una vez abiertos todos los paréntesis y agrupados los términos semejantes, queda vestida como f(x) = ax2 + bx + c con el coeficiente principal a ≠ 0. Esa última condición no es un capricho burocrático: si al desarrollar una expresión como f(n) = 2(n − 1)2 − 2n2 los términos con n2 se cancelan entre sí (2n2 − 2n2 = 0), lo que parecía una parábola se desinfla y queda la recta f(n) = −4n + 2.

Cuidado con la trampa de examen: En (2 − 3x)2, la tentación automática es repartir el exponente y escribir 4 − 9x2. ¡Error doble! Primero, te comiste el doble producto 2 · 2 · (−3x) = −12x; segundo, el cuadrado de −3x es (−3x) · (−3x) = +9x2 positivo. El desarrollo verdadero es 9x2 − 12x + 4.

2. Ingeniería Inversa: Factor Común y el Rompecabezas Suma-Producto (a = 1)

Factorizar un polinomio no es aprender una regla marciana: es simplemente rebobinar la película del Pizarrón 1. Hace un minuto teníamos las medidas de los lados (x + m)(x + n) y calculábamos el área total desplegada. Ahora nos dan el área total ya sumada, por ejemplo x2 + 5x + 6, y queremos descubrir cuánto medían la base y la altura originales.

La pista del detective: dónde viven la Suma y el Producto

Si desarrollamos con letras generales el producto de dos binomios con coeficiente principal a = 1, las cuatro parcelas del rectángulo nos revelan el secreto:

(x + m) · (x + n) = x2 + mx + nx + m · n = x2 + (m + n)x + m · n

Comparando término a término con x2 + bx + c, quedan al descubierto las dos condiciones: buscamos dos números m y n tales que su producto sea el número suelto c (m · n = c) y su suma sea el coeficiente lineal b (m + n = b).

Para no adivinar a ciegas, leé primero los signos como una brújula: si el producto c es positivo, ambos números tienen obligatoriamente el mismo signo (ambos positivos si b > 0, como en x2 + 5x + 6 = (x + 2)(x + 3); ambos negativos si b < 0, como en x2 − 5x + 6 = (x − 2)(x − 3)). En cambio, si el producto c es negativo, uno es positivo y el otro es negativo, y gana en tamaño absoluto el que lleva el signo de b: por ejemplo, en x2 − x − 42, los divisores vecinos −7 y +6 multiplican −42 y suman −1, dando (x − 7)(x + 6).

Cuidado con invertir suma y producto: Un tropiezo frecuente bajo presión es buscar dos números que sumen c y multipliquen b. Recordá siempre el modelo de área: la esquina sin x nace de multiplicar las dos constantes (m · n = c), mientras que las dos tiras con x se suman entre sí (m + n = b).

3. Cuando a ≠ 1: El Arte de Agrupar y la Brújula de los 5 Pasos

¿Por qué cuando delante de x2 hay un número distinto de 1 —como en 2x2 + 7x + 3— ya no alcanza con buscar divisores de 3 que sumen 7? Porque ese coeficiente a = 2 multiplica a una de las tiras laterales del rectángulo. Para reconstruir las cuatro parcelas originales sin adivinar, buscamos dos números m y n que multiplicados den el producto de las puntas a · c (acá 2 · 3 = 6) y sumados den el término central b = 7.

Cocina paso a paso de la Factorización por Agrupación

En 2x2 + 7x + 3, los números que multiplican 6 y suman 7 son 1 y 6. Esos dos números sirven para desarmar el término del medio 7x = 1x + 6x y volver a ver las cuatro parcelas:

2x2 + 7x + 3 = (2x2 + 1x) + (6x + 3) = x · (2x + 1) + 3 · (2x + 1) = (2x + 1) · (x + 3)

Peligro del signo menos en el tercer término: Si al desarmar 3x2 − 10x + 8 te queda 3x2 − 6x − 4x + 8, en la primera pareja sacás 3x(x − 2). Para que en la segunda pareja −4x + 8 aparezca idéntico el paréntesis (x − 2), tenés que extraer −4 negativo: como +8 : (−4) = −2, queda −4(x − 2), cerrando limpio en (3x − 4)(x − 2).

Para enfrentar cualquier polinomio en un parcial sin entrar en pánico, seguí la Brújula de 5 Preguntas en orden: 1.º ¿Hay un factor común en todos los términos que achique los números? (ej. en 5x2 − 80 sacás el 5 y queda 5(x2 − 16)); 2.º ¿Es una diferencia de cuadrados?; 3.º ¿Es un trinomio cuadrado perfecto? (ej. 4x2 + 12x + 9 = (2x + 3)2); 4.º Si a = 1, ¿sale por suma-producto?; 5.º Si a ≠ 1, ¿sale por agrupación con a · c?

Cuidado con olvidarte del factor común inicial: Si en 4x2 + 18x − 10 sacás primero el factor común 2 para trabajar más liviano con 2x2 + 9x − 5, ese 2 sigue siendo parte de la función y debe quedar multiplicando adelante en la respuesta final: 2(2x − 1)(x + 5).

4. De la «V» a la Curva: Forma Canónica f(x) = a(x − xᵥ)² + yᵥ y Despeje por Raíz

Si venís del laboratorio de Valor Absoluto, esta estructura te va a resultar recontra familiar: en a|x − h| + k los escalones subían de forma rígida (1, 2, 3…) formando una «V» puntiaguda. Ahora cambiamos las barras de módulo por un paréntesis al cuadrado y obtenemos la forma canónica: f(x) = a(x − xv)2 + yv. Al elevar al cuadrado respecto de la parábola matriz y = x2, cuando te alejás 1, 2, 3 unidades horizontalmente desde el vértice, la altura salta como los cuadrados 1a, 4a, 9a, dibujando esa curva suave llamada parábola.

¿Por qué la coordenada horizontal del vértice (xv) se lee con el signo cambiado respecto al paréntesis? No es brujería: como cualquier número real elevado al cuadrado da siempre 0 o positivo, el paréntesis (x − xv)2 toca su piso más bajo posible únicamente cuando su interior vale exactamente cero (x − xv = 0 ⇒ x = xv). Justo en ese valor de x el término cuadrático se apaga y la altura de la curva queda clavada en yv. El signo del coeficiente a decide la concavidad: si a > 0 abre las ramas hacia arriba (∪) teniendo un piso mínimo; si a < 0 abre hacia abajo (∩) teniendo un techo máximo.

Cómo hallar las raíces desde la Forma Canónica sin desarrollar todo el polinomio

Si tenés 2(x − 3)2 − 8 = 0, expandir el cuadrado para después aplicar la resolvente es trabajar el doble. Despejá directamente el paréntesis al cuadrado:

2(x − 3)2 = 8 ⇒ (x − 3)2 = 4 ⇒ √((x − 3)2) = √4 ⇒ |x − 3| = 2

Recordando que √(u2) = |u| abre dos caminos simétricos (x − 3 = ±2), sumás 3 y obtenés al instante x1 = 3 − 2 = 1 y x2 = 3 + 2 = 5.

Cuidado con confundir yv con la ordenada al origen: En f(x) = −5(x + 1)2 − 6, el vértice es (−1; −6), pero la curva NO corta al eje Y en −6. Para hallar la ordenada al origen hay que evaluar x = 0: f(0) = −5(0 + 1)2 − 6 = −5 − 6 = −11.

5. La Forma Factorizada f(x) = a(x − x₁)(x − x₂) y el Secreto del Espejo

Si la forma canónica te regala el vértice en bandeja, la forma factorizada f(x) = a(x − x1)(x − x2) te regala los puntos donde la parábola pisa el suelo del eje X (sus raíces x1 y x2). Funciona gracias a la propiedad del producto cero: para que una multiplicación dé 0, alcanza con que cualquiera de los paréntesis valga 0 (x = x1 o x = x2).

El atajo del espejo: cómo hallar el vértice promediando las raíces

Como toda parábola es perfectamente simétrica respecto de su eje de simetría, el vértice cae siempre justo a mitad de camino entre las dos raíces (su promedio aritmético):

xv = x1 + x22  ⇒  yv = f(xv)

Una vez que calculaste ese punto medio xv, simplemente lo metés adentro de la fórmula factorizada para saber qué tan alto o qué tan bajo llega el vértice (yv = f(xv)), ¡sin necesidad de expandir el polinomio!

Cuando aparece una cuadrática incompleta como x2 − 4x = 0, la tentación escolar número uno es pasar el 4x al otro lado (x2 = 4x) y «tachar una x de cada lado» para decir que x = 4. ¡Trampa mortal de parcial! Cuando dividís ambos lados por x, estás asumiendo en secreto que x no vale cero (porque dividir por cero está prohibido), y al hacerlo matás la solución x = 0. El camino limpio es sacar factor común: x · (x − 4) = 0. Ahora tenés dos piezas multiplicándose que dan cero: o vale cero la primera (x1 = 0) o vale cero la segunda (x − 4 = 0 ⇒ x2 = 4).

Cuidado al reconstruir una parábola desde sus raíces: Si te dicen que una parábola corta al eje X en −1 y en 3 y pasa por (0; 6), no escribas solamente (x + 1)(x − 3). Tenés que incluir adelante el coeficiente principal a: planteás f(x) = a(x + 1)(x − 3), reemplazás 6 = a(1)(−3) y despejás a = −2.

6. El Puente Alquimista: Completar el Cuadrado y por qué xᵥ = −b / (2a)

La mayoría de las veces te tiran la cuadrática vestida en forma polinómica (f(x) = ax2 + bx + c), donde el único dato gratis es la ordenada al origen f(0) = c, pero tanto el vértice como las raíces están escondidos. En vez de memorizar la fórmula xv = −b / (2a) como un versito ciego, abramos la cocina completa con el método geométrico de completar el cuadrado.

La cocina completa paso a paso: de x2 − 6x + 2 a (x − 3)2 − 7

Paso 1 (Partir las alas): Tomamos el término lineal −6x y lo partimos en dos mitades iguales de −3x para armar los dos bordes de un cuadrado de lado (x − 3).

Paso 2 (Fabricar el neutro aditivo +0): Para cerrar la esquina de ese cuadrado de lado (x − 3) nos falta un cuadradito numérico de (−3)2 = 9. Como no podemos alterar la función, sumamos y restamos 9 en el mismo renglón (que equivale a sumar +0):

x2 − 6x + 2 = (x2 − 6x + 9) − 9 + 2 = (x − 3)2 − 7

Paso 3 (¿Y si a ≠ 1?): En ax2 + bx + c, primero extraemos a de los términos con x: a[x2 + (b/a)x] + c. La mitad del coeficiente lineal dentro del corchete es b / (2a), por lo que el cuadrado se cierra en (x + b/(2a))2. ¡De ahí nace para siempre que el vértice vive en xv = −b / (2a)!

Cuidado con el factor a al salir del corchete: En 3x2 − 6x − 1, al armar 3[(x2 − 2x + 1) − 1] − 1, ese −1 restado adentro del corchete está multiplicado por el 3 de adelante: sale como −3, dando 3(x − 1)2 − 4 (y no −2).

7. La Fórmula Resolvente por Dentro, el Radar Δ y Cardano-Vieta

La famosa Fórmula Resolvente (o de Bhaskara) no cayó del cielo: es simplemente igualar a cero la forma canónica obtenida en el Pizarrón 6 y despejar la x. Si en lugar de memorizar un bloque compacto la escribís separada en dos términos, su significado geométrico salta a la vista:

El primer término −b / (2a) te para en el eje de simetría xv, y el segundo término suma y resta la distancia horizontal hasta cada raíz. Por eso lo que está adentro de la raíz cuadrada —el discriminante Δ = b2 − 4ac— decide cuántas veces la parábola corta al eje X:

Los tres veredictos del Radar Δ y las Propiedades de Cardano-Vieta

• Si Δ > 0: La raíz cuadrada de un positivo existe y es mayor que cero; caminás esa distancia a izquierda y derecha de xv y tenés 2 raíces reales distintas (racionales si Δ es cuadrado perfecto, o irracionales conjugadas como 3 ± √7).
• Si Δ = 0: Sumás y restás cero (xv ± 0); las dos raíces se funden en 1 única raíz real doble (x1 = x2 = xv) y la parábola es tangente al eje X.
• Si Δ < 0: En ℝ no existe la raíz cuadrada de un número negativo; la parábola flota entera arriba o abajo del eje X y no tiene raíces reales (C0 = ∅).

Además, por las relaciones de Cardano-Vieta, al sumar las dos ramas de la resolvente las raíces cuadradas se cancelan dando x1 + x2 = −b / a, y al multiplicarlas por diferencia de cuadrados queda x1 · x2 = c / a.

Cuidado con los signos cuando b es negativo: Si b = −6, adelante en la resolvente va −b = −(−6) = +6 positivo, y adentro del discriminante va (−6)2 = +36 positivo. Escribir −62 = −36 arruina todo el discriminante.

8. Radiografía Completa: Imagen, Signos (C⁺, C⁻), Monotonía y Biyectividad

Acá es donde medio curso pierde puntos por mezclar los dos ejes. Imaginá que caminás sobre el gráfico de f(x) = −(x + 3)2 + 1 de izquierda a derecha: tus pies avanzan por el piso (el eje X) y tu cabeza mide la altura (el eje Y). Mientras venís desde −∞ hasta el kilómetro x = −3, estás subiendo la montaña: por eso el intervalo de crecimiento es I↑ = (−∞; −3) y el de decrecimiento es I↓ = (−3; +∞), ¡mirando siempre el piso X en xv, nunca la altura 1!

En cambio, cuando te piden la Imagen, te preguntan qué alturas alcanza el dibujo sobre el eje Y. A diferencia de las funciones exponenciales —donde la asíntota horizontal llevaba paréntesis abierto porque la curva jamás la tocaba—, en una parábola el vértice es un punto real que la curva sí pisa. Por eso en yv va siempre corchete cerrado: [yv; +∞) si a > 0, o (−∞; yv] si a < 0.

Positividad (C+), Negatividad (C−) y por qué restringimos el dominio para invertir

• Conjuntos de signos: Miramos en qué tramos del eje X la parábola vuela por encima del eje X (C+) o se hunde por debajo (C−). Ojo cuando la parábola rebota en una raíz doble xv (por ejemplo f(x) = −2(x − 1)2): en x = 1 vale exactamente 0, así que para la negatividad hay que excluir ese punto: C− = (−∞; 1) ∪ (1; +∞) = ℝ − {1}.
• Biyectividad e Inversa: Ninguna cuadrática con dominio ℝ es inyectiva (dos valores simétricos xv − d y xv + d tienen la misma altura) ni suryectiva en ℝ. Para hacerla biyectiva y poder invertirla con una raíz cuadrada, nos quedamos con una sola rama a partir del vértice: [xv; +∞) → Im(f) o (−∞; xv] → Im(f).

Cuidado con los dos errores clásicos de parcial en análisis de parábolas: 1) Nunca pongas paréntesis abierto en yv al escribir la Imagen (va corchete cerrado). 2) Nunca metas yv en los intervalos de crecimiento o decrecimiento (quiebran siempre en xv).

9. Encuentros en el Plano: Sistemas Parábola-Recta y Recta Tangente

¿Qué pasa cuando lanzamos un rayo láser recto g(x) = mx + d hacia una parábola f(x) = ax2 + bx + c? Buscar dónde se chocan es pedir que en el mismo valor horizontal x ambas tengan exactamente la misma altura y: igualamos ax2 + bx + c = mx + d. Al restar mx + d en ambos lados para dejar un 0 a la derecha, nos queda una nueva ecuación cuadrática diferencia:

ax2 + (b − m)x + (c − d) = 0  con  Δint = (b − m)2 − 4a(c − d)

Cómo usar Δint = 0 para cazar rectas tangentes con parámetro k

El discriminante de intersección Δint decide la geometría del encuentro: si Δint > 0 la recta corta en 2 puntos (es secante); si Δint < 0 no la toca nunca (exterior); y si Δint = 0 se tocan en 1 único punto y tenemos una recta tangente a una parábola.

Por ejemplo, para hallar qué pendiente k hace que la recta y = kx − 1 sea tangente a y = x2 + 2x + 3, igualamos x2 + 2x + 3 = kx − 1 ⇒ x2 + (2 − k)x + 4 = 0. Exigimos Δint = (2 − k)2 − 4 · 1 · 4 = 0 ⇒ (2 − k)2 = 16 ⇒ |2 − k| = 4, de donde brotan las dos rectas tangentes posibles: k1 = −2 y k2 = 6.

Cuidado con entregar solo la coordenada x: Un punto de intersección en el plano tiene dos coordenadas (x; y). Después de resolver la ecuación cuadrática igualada para hallar x, reemplazá cada valor en la ecuación de la recta y = mx + d para encontrar su altura y correspondiente.

10. Dominar los Extremos: Proyectiles, Cercos y el Misterio del Cuadrado Inscrito

En los problemas aplicados nadie te dice «calculá el vértice»; te preguntan «¿cuál es la altura máxima que alcanza el proyectil?», «¿qué dimensiones maximizan el área del terreno cercado?» o «¿qué corte minimiza la superficie de la pieza?». En cuanto armás la fórmula y ves que la variable aparece elevada al cuadrado (x2 o t2), sabés que el gráfico es una parábola y que el extremo buscado es simplemente el vértice (xv; yv): xv responde «para qué valor de la variable ocurre» e yv responde «cuánto vale ese máximo o mínimo».

El problema estrella desarmado paso a paso: El cuadrado inscrito en un cuadrado de 16 cm

Dentro de un cuadrado exterior de 16 cm de lado inscribimos otro cuadrado MNOP marcando una distancia x desde cada esquina. En las cuatro esquinas quedan cuatro triángulos rectángulos idénticos cuyos catetos miden x y 16 − x.

Por el Teorema de Pitágoras, el lado L del cuadrado interior cumple L2 = x2 + (16 − x)2. Y como el área del cuadrado interior es justamente S(x) = L2, al desarrollar el binomio obtenemos la función cuadrática sobre su dominio físico x ∈ [0; 16]:

S(x) = x2 + (256 − 32x + x2) = 2x2 − 32x + 256

Como a = 2 > 0, la parábola abre hacia arriba y alcanza su área mínima en el punto medio xv = −(−32) / (2 · 2) = 8 cm, donde vale S(8) = 128 cm2 (exactamente la mitad del cuadrado exterior). En cambio, el área máxima (256 cm2) se alcanza en los bordes del dominio físico: x = 0 cm o x = 16 cm.

Cuidado con confundir xv con yv en la respuesta final: Leé con lupa si el enunciado pregunta «¿cuánto debe medir el corte x?» (respuesta: xv = 8 cm) o «¿cuál es el área mínima alcanzada?» (respuesta: yv = 128 cm2).

Síntesis de Estudio · Unidad 05

Hoja de Repaso Imprimible · Función Cuadrática y Parábolas

1. Las Tres Formas de la Parábola (a ≠ 0)

Polinómica: f(x) = ax2 + bx + c → regala la ordenada al origen f(0) = c.

Canónica: f(x) = a(x − xv)2 + yv → regala el vértice V(xv; yv) y el eje x = xv.

Factorizada: f(x) = a(x − x1)(x − x2) → regala las raíces reales x1, x2 (cuando Δ ≥ 0).

2. Puentes Rápidos hacia el Vértice

Desde Polinómica: xv = −b / (2a) y luego yv = f(xv).

Desde Factorizada (Espejo): xv = (x1 + x2) / 2 y luego yv = f(xv).

Completar el cuadrado: Sumar y restar (b/(2a))2 adentro del corchete (neutro +0) y multiplicar por a al salir.

3. Resolvente, Radar Δ y Cardano-Vieta

Fórmula Resolvente: x1,2 = −b/(2a) ± √Δ/(2a) con Δ = b2 − 4ac.

Naturaleza de raíces: Δ > 0 (2 reales distintas) · Δ = 0 (1 raíz doble, rebota) · Δ < 0 (sin raíces reales, C0 = ∅).

Cardano-Vieta: x1 + x2 = −b/a  |  x1 · x2 = c/a.

4. Radiografía Exactas e Intersecciones
